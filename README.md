# psi.zse

Sistema de repasses para as psicólogas da Clínica Imaginare: sessões, faltas, períodos da Unimed e quanto cada uma recebe.

- Site: https://vizsestudio-lab.github.io/psizse/
- Banco e login: Supabase (cada psicóloga vê só os próprios pacientes; acesso liberado pela administração)

Este repositório guarda apenas o código do site. Nenhum dado de paciente fica aqui.
